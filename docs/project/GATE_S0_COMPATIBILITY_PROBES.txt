The repository has no LICENSE/COPYING/NOTICE file. Its PIPER-X source is not Gate C
equivalent: link names are Link1..Link8 rather than link1..link6 plus flange/TCP;
joint-1 zero-frame RPY is 0 instead of Gate C pi; joints 2, 4, 5, and 6 use different
origins; joint-4/5/6 limits are approximately +/-90, +/-90, +/-180 degrees rather
than Gate C +/-89, +/-89, +/-120 degrees; masses/inertias differ; and the gripper is
two independent prismatic joints without Gate C's aperture/mimic contract. The USD
is therefore a reference only, not the selected embodiment.

9. MuJoCo embodiment candidates
--------------------------------

The official AgileX piper_isaac_sim tree has generic Piper MJCF under
piper_description/mujoco_model, but no PIPER-X MJCF under piper_x_description.
The generic file identifies model="piper" and has limits/control ranges that do
not match Gate C; it is rejected as the PIPER-X embodiment. No Piper model was
found in the audited MuJoCo Menagerie listing, and Menagerie itself states that it
is not an officially supported Google product. The selected M1 strategy is a
deterministic Gate C URDF-to-MJCF derivation using MuJoCo's public parser/save
boundary, followed only by task actuators, cameras, and verified gripper coupling.

Overall probe verdict
---------------------

MuJoCo -> core: PASS.
Isaac supported same-process environment: BLOCKED.
Isaac host eligibility for 6.0.1: BLOCKED.
Gate S0 cannot be accepted until both Isaac blocker classes are cleared and the
candidate dependency set resolves without unsupported upstream overrides.
